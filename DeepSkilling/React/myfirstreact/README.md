# My First React Application

## Objective

Create a React application named **myfirstreact** that displays:

**Welcome to the first session of React**

## Technologies Used

- React
- JavaScript
- Node.js
- npm

## Project Structure

```
myfirstreact
│
├── public
├── src
│   └── App.js
├── package.json
└── README.md
```

## Run the Project

```bash
npm install
npm start
```

Open:

```
http://localhost:3000
```

## Output

```
Welcome to the first session of React
```
